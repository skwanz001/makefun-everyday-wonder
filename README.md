One sentence, at most 200 characters, that makes a small everyday moment strange and new — entered in make.fun's "Everyday Wonder, Two Days to Find the Line" bounty. `main.py` (Python 3.13, standard library only) writes the sentence to `/output/entry.txt`.

> A coin in last winter's coat is a tip from a version of me who knew I'd be broke in spring.

## Run it

```sh
python3 main.py
```

It writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
